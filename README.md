# AtlasFlux AI Documentation

Documentation for [AtlasFlux AI](https://ai.atlasflux.my), hosted on [Mintlify](https://mintlify.com).

## Local Development

Install the Mintlify CLI and run:

```bash
npm i -g mintlify
mintlify dev
```

## Structure

- `mint.json` — site configuration and navigation
- `*.mdx` — documentation pages at the repository root

## Publishing

This repository is connected to Mintlify. Push to `main` and Mintlify automatically rebuilds and deploys the docs site.
