# PWA Installation

AtlasFlux AI is a **Progressive Web App**. Install for quick access:

- **Desktop**: click the **install icon** in the address bar.
- **iOS**: **Share** → **Add to Home Screen**.
- **Android**: **Menu** → **Install app**.
