# All AI Tools – Complete Reference

Every tool has its own dedicated page and history. Text-based tools are free. Billable audio, image, and video tools consume Credits as listed below. Access all tools from the [Tools Hub](https://ai.atlasflux.my/tools).

| Tool | Cost | Description |
| ---- | ---- | ----------- |
| AI Image Generator | Credits (varies by model) | More than 100 models. Select a model, configure settings, and see the live Credit estimate before generation. |
| Video Generation | Credits (varies by model) | Create videos from text, images, or clips. The Credit estimate depends on model, resolution, duration, and audio. |
| Music Generator | Lyrics: Free \| Audio: 30-50 credits | Create original songs with AI. Choose Lyria or MiniMax models. Generate lyrics for free, then turn them into audio. Edit lyrics before finalising. 2 free audio trials for MiniMax 1.5. [History: Music Album](https://ai.atlasflux.my/tools/music/history). |
| Voice Cloning | 15 credits | Clone any voice by uploading a short sample (5-10 sec). Supports 15 languages. Download the generated speech. [History: Voice Cloning History](https://ai.atlasflux.my/tools/voice-cloning/history). |
| Audio Separation | 20 credits | Separate an audio file into stems (vocals, drums, bass, other). Adjustable model, overlap, and MP3 settings. [History: Audio Separation History](https://ai.atlasflux.my/tools/audio-separation/history). |
| Paraphrase | Free | Rewrite text in different styles (Standard, Formal, Casual, Creative). Adjust creativity level. [History: Paraphrase History](https://ai.atlasflux.my/tools/paraphrase/history). |
| Prompt Creator | Free | Craft detailed image/video prompts. Configure type, style, lighting, mood, composition. Output as text or JSON. [History: Prompt History](https://ai.atlasflux.my/tools/image-prompt/history). |
| Face Restoration | 5 credits | Restore old/damaged faces using GFPGAN. Choose scale (2x/4x) and model version. Before-after comparison. [History: Face Restoration History](https://ai.atlasflux.my/tools/face-restoration/history). |
| Remove Background | 10 credits | Instantly remove image backgrounds (BRIA RMGB 2.0). Output: transparent PNG. Before-after comparison. [History: Remove BG History](https://ai.atlasflux.my/tools/remove-background/history). |
| Upscaler | 10 credits | Enhance resolution up to 4x with Real-ESRGAN. Optional face enhancement for portraits. Before-after slider. [History: Upscaler History](https://ai.atlasflux.my/tools/upscaler/history). |
| Image to 3D | 70 credits | Generate 3D model (GLB) from image/text. Adjustable face count, PBR materials. Interactive 3D viewer. [History: Image to 3D History](https://ai.atlasflux.my/tools/image-to-3d/history). |
| Image Tools | 5-15 credits | Poster Maker (RAD Posters, 5 cr) and Remove Object (Flux Fill Pro, 15 cr). Upload mask for removal. [History: Image Tools History](https://ai.atlasflux.my/tools/image-tools/history). |
